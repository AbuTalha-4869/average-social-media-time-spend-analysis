# 📊 Average Social Media Time Analysis 🚀
### 📱 Exploring Digital Habits Through Business Analytics

**IBM Project | Microsoft Power BI | Data Analytics & Visualization**

## 🌟 Project Overview

In today's digital world, social media platforms have become an important part of people's daily lives. Platforms such as Instagram, YouTube, and Facebook allow users to connect, communicate, learn, entertain themselves, and explore their interests.

The **Average Social Media Time Analysis** project focuses on understanding social media usage patterns among 1,000 users through an interactive Power BI dashboard.

This project explores average time spent across different platforms and examines how usage patterns vary according to age, gender, residential area, profession, and interests. It also presents the distribution of users by debt status.

By converting raw data into meaningful visualizations, the dashboard makes it easier to compare user groups, identify patterns, and communicate analytical findings.

🎯 **The primary goal is to transform social media data into clear, understandable, and meaningful insights using business analytics and data visualization.**

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🎯 Project Objectives

The major objectives of this project are:

- 📱 **Platform Analysis:** Compare Instagram, YouTube, and Facebook based on user counts and average time spent.
- ⏱️ **Time-Spent Analysis:** Understand the average, minimum, and maximum values of the time-spent metric.
- 👥 **Demographic Analysis:** Explore the distribution of users across different demographic categories.
- ⚧️ **Gender Analysis:** Examine gender representation across social media platforms.
- 🎂 **Age-Based Analysis:** Identify variations in average time spent across the displayed age groups.
- 💼 **Profession-Based Analysis:** Compare usage patterns among marketers/managers, students, and software engineers.
- 🏙️ **Location Analysis:** Understand the distribution of users across rural, sub-urban, and urban areas.
- 💳 **Debt Status Analysis:** Examine the proportion of users classified by debt status.
- ❤️ **Interest Analysis:** Explore the representation of Lifestyle, Sports, and Travel interests.
- 📊 **Data Visualization:** Present multiple analytical perspectives through a consolidated Power BI dashboard.

## ✨ Dashboard Features

The KPI section provides a quick overview of the dataset.

- 👥 **User Count — 1K:** Represents the total number of users analyzed.
- 🎂 **Average Age — 40.99:** Summarizes the average age shown on the dashboard.
- ⏱️ **Average Time Spent — 5.03:** Displays the mean value of the time-spent metric.

These metrics allow viewers to understand the overall dataset before exploring individual charts.

### 📱 2. Platform-Wise Analysis

The dashboard compares three platforms: Instagram, YouTube, and Facebook.

Approximate user counts read from the dashboard:

- 📸 Instagram — 362 users
- ▶️ YouTube — 331 users
- 📘 Facebook — 307 users

Instagram has the highest approximate user count, while Facebook has the lowest among the three platforms.

The dashboard also compares average time spent by platform. The approximate values are:

- 📸 Instagram — 5.2
- 📘 Facebook — 5.1
- ▶️ YouTube — 4.9

The differences are relatively small, suggesting that the displayed average time-spent scores are similar across the three platforms.

### 👥 3. Demographic Distribution

The demographic chart shows how the 1,000 users are distributed across three residential categories.

- 🌾 Rural — 34%
- 🏘️ Sub-Urban — 33.5%
- 🏙️ Urban — 32.5%

The difference between the largest and smallest categories is only 1.5 percentage points.

This indicates that the dataset has a relatively balanced residential distribution, allowing comparisons across all three categories.

### ⚧️ 4. Gender Distribution by Platform

The dashboard includes a 100% stacked chart showing female, male, and non-binary representation across Instagram, YouTube, and Facebook.

This visualization helps viewers compare the composition of users within each platform rather than simply comparing the total number of users.

The displayed chart does not show an overwhelming dominance by a single gender category across all platforms.

The exact proportions should be treated as approximate readings from the visualization.

### 💼 6. Profession-Based Analysis

The dashboard compares average time spent among three professional categories.

- 📣 Marketer Manager — approximately 5.15
- 🎓 Student — approximately 5.05
- 💻 Software Engineer — approximately 4.95

All three values are close to 5, with only a small difference between the highest and lowest categories.

This makes it possible to compare the displayed usage patterns across the three professional groups.

### 💳 7. Debt Status Analysis

The debt-status visualization divides users into two categories.

- ✅ Not in debt — 503 users, representing 50.3%
- ⚠️ In debt — 497 users, representing 49.7%

The difference between the groups is six users, equivalent to 0.6 percentage points.

The chart therefore shows an almost equal distribution of users across the two categories.

This analysis describes the distribution of debt status only. It does not demonstrate that social media usage causes debt or that debt status determines the amount of time spent online.

### ❤️ 8. Interests Analysis

The interests visualization represents three categories:

- 🌿 Lifestyle
- ⚽ Sports
- ✈️ Travel

The treemap displays these categories with approximately similar areas, suggesting a relatively balanced representation of the three interests.

The proportions are visual estimates rather than exact counts confirmed by the dashboard.

## 🧠 Analytical Methodology

The project follows a straightforward data-analysis workflow:

### 📁 Step 1 — Understand the Dataset

Identify the user-related fields represented in the dashboard, such as platform, age, gender, time spent, profession, income, debt status, and interests.

### 📊 Step 2 — Summarize the Information

Review the displayed user count and KPI values to understand the overall dataset.

### 🔎 Step 3 — Compare Categories

Compare platform-wise, demographic, age-wise, profession-wise, debt-status, and interest distributions.

### 🎨 Step 4 — Visualize the Findings

Use dashboard charts and KPI cards to present the information in a visually understandable format.

### 💡 Step 5 — Interpret the Results

Identify the largest categories, similarities, differences, and variations visible in the dashboard.
